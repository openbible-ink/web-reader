# Strong’s lexicon data

`lexicon.json` contains the Hebrew and Greek dictionaries from the
[Open Scriptures Strong’s project](https://github.com/openscriptures/strongs).

- Original dictionaries: James Strong, 1890/1894 (public domain)
- JSON editions: Open Scriptures, CC BY-SA
- Greek JSON copyright notice: 2009 Open Scriptures
- Hebrew JSON copyright notice: 2010 Open Scriptures
- Retrieved: 24 November 2026

The data is served locally by the word-study API. It must not be bundled into
the main reader JavaScript payload.
